## Задание 1. Скидка на заказ

Исходный код: [`task1_discount.cpp`](task1_discount.cpp)

**Входные данные**

| | Значение | Тип |
|---|---|---|
| Вход | `cost` — стоимость заказа, неотрицательное число | `double` |
| Вход | `isStudent` — признак студента: 1 — да, 0 — нет | `int` |

**Правила**

| Условие | Скидка |
|---|---|
| `cost >= 60` | 10 % |
| `cost >= 30` | 5 % |
| студент | 7 % |

Скидки **не складываются** — применяется одна, максимальная. При `cost < 0` выводится ошибка.

**Результат:** выбранный процент скидки и итоговая сумма заказа.

### Примеры работы

```
Введите стоимость заказа: 20
Студент (1 - да, 0 - нет): 0
Стоимость заказа: 20
Выбранная скидка: 0 %
Итоговая сумма: 20
```

```
Введите стоимость заказа: 30
Студент (1 - да, 0 - нет): 0
Стоимость заказа: 30
Выбранная скидка: 5 %
Итоговая сумма: 28.5
```

```
Введите стоимость заказа: 45
Студент (1 - да, 0 - нет): 1
Стоимость заказа: 45
Выбранная скидка: 7 %
Итоговая сумма: 41.85
```

```
Введите стоимость заказа: 60
Студент (1 - да, 0 - нет): 1
Стоимость заказа: 60
Выбранная скидка: 10 %
Итоговая сумма: 54
```

```
Введите стоимость заказа: -5
Студент (1 - да, 0 - нет): 0
Ошибка: стоимость заказа не может быть отрицательной.
```

Наборы с `45` и `60` показывают, что при наличии студенческой скидки действует именно
максимальная из двух: 7 % вместо 5 %, но 10 % вместо 7 %.

## Задание 3. Меню и скидка за объём

Исходный код: [`task3_menu.cpp`](task3_menu.cpp)

**Входные данные**

| | Значение | Тип |
|---|---|---|
| Вход | `code` — код блюда: M — основное, S — суп, D — десерт | `char` |
| Вход | `portions` — количество порций от 1 до 20 | `int` |

Цена одной порции задаётся через `switch`. При `portions >= 5` на блюда действует скидка 8 %.
Количество вне диапазона 1..20 — ошибка.

| Код | Категория | Цена порции |
|---|---|---|
| `M` | Основное блюдо | 9 |
| `S` | Суп | 6 |
| `D` | Десерт | 4 |

## Задание 4. Заказ со скидками и доставкой

Исходный код: [`task4_order.cpp`](task4_order.cpp)

**Входные данные**

| | Значение | Тип |
|---|---|---|
| Вход | `code` — код блюда: M — основное, S — суп, D — десерт | `char` |
| Вход | `portions` — количество порций от 1 до 20 | `int` |
| Вход | `isStudent` — признак студента: 1 — да, 0 — нет | `int` |
| Вход | `delivery` — признак доставки: 1 — да, 0 — нет | `int` |

**Правила**

| Условие | Скидка |
|---|---|
| `portions >= 5` | 8 % |
| студент | 10 % |

Применяется только большая из двух скидок. Стоимость блюд считается как `цена × количество`,
затем из неё вычитается скидка. Доставка добавляет 5, но если сумма блюд **после скидки**
от 50 — доставка бесплатна.

Ошибка выводится, если количество вне диапазона 1..20 или код блюда неизвестен.

**Результат:** стоимость блюд, скидка, стоимость доставки и итоговая сумма.

```

Введите количество порций (1..20): 2
Студент (1 - да, 0 - нет): 0
Доставка (1 - да, 0 - нет): 1
Стоимость блюд: 18
Скидка: 0 %
Сумма блюд после скидки: 18
Доставка: 5
Итого: 23
```

```
Введите код блюда (M - основное, S - суп, D - десерт): M
Введите количество порций (1..20): 5
Студент (1 - да, 0 - нет): 0
Доставка (1 - да, 0 - нет): 1
Стоимость блюд: 45
Скидка: 8 %
Сумма блюд после скидки: 41.4
Доставка: 5
Итого: 46.4
```

```
Введите код блюда (M - основное, S - суп, D - десерт): S
Введите количество порций (1..20): 10
Студент (1 - да, 0 - нет): 1
Доставка (1 - да, 0 - нет): 0
Стоимость блюд: 60
Скидка: 10 %
Сумма блюд после скидки: 54
Доставка: 0
Итого: 54
```

```
Введите код блюда (M - основное, S - суп, D - десерт): M

```

Набор из 20 порций показывает бесплатную доставку: 165.6 — это от 50.

Граничный случай скидки студента — 6 порций основного блюда:

```
Введите код блюда (M - основное, S - суп, D - десерт): M
Введите количество порций (1..20): 6
Студент (1 - да, 0 - нет): 1
Доставка (1 - да, 0 - нет): 1
Стоимость блюд: 54
Скидка: 10 %
Сумма блюд после скидки: 48.6
Доставка: 5
Итого: 53.6
```

Здесь блюд 54, но скидка 10 % больше, чем 8 % за объём, поэтому итог по блюдам 48.6 —
это меньше 50, и доставка остаётся платной.

